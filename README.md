# Reconciliation Tool (1C vs Bank Statements)

Сверка данных учётной системы (1С) с банковскими выписками: поиск расхождений, непроведённых операций и ошибок учёта.

## Проблема
При аудите малого бизнеса обнаружены расхождения между данными 1С и банковскими выписками (тысячи входящих и исходящих документов за год). Ручная сверка такого объёма — недели работы и высокий риск пропустить ошибку.

## Решение
Скрипт, который:
1. Загружает выгрузку из 1С и банковскую выписку (Excel/CSV)
2. Нормализует данные и сопоставляет операции
3. Находит расхождения: непроведённые документы, отсутствующие платежи, несовпадение сумм
4. Формирует отчёт для бухгалтера

Проект реализуется в AI-assisted режиме (Cursor / Claude): постановка задачи, проектирование логики сверки, тестирование.

## Важно
Репозиторий содержит демо-версию на синтетических данных. Реальный кейс выполнялся вручную в ходе аудита — коммерческие данные клиента не публикуются.

## Результат
- Подтверждённый ручной кейс: полная сверка годового массива документов (1С ↔ банк), все расхождения найдены и задокументированы
- Автоматизация сводит сверку к загрузке двух файлов и запуску скрипта

## Стек
Python, Excel/CSV
