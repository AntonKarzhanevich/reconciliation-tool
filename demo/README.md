# Демо-данные сверки (синтетические)

Все данные выдуманы и не относятся ни к одному реальному клиенту.

- `bank_statement_demo.csv` — фрагмент «банковской выписки»: 10 платежей
- `1c_export_demo.csv` — фрагмент «выгрузки из 1С»: тот же период, но с типовыми ошибками учёта
- `report_demo.csv` — результат сверки (генерируется скриптом)

## Заложенные расхождения (4)

1. `BS-1003` — платёж есть в банке, в 1С не проведён → `MISSING_IN_1C`
2. `BS-1005` — сумма 1500.00 в банке против 15000.00 в 1С → `AMOUNT_MISMATCH`
3. `BS-1007` — дата в 1С с опечаткой в годе → `DATE_MISMATCH`
4. `ZH-2001` — документ есть в 1С, в банке отсутствует → `MISSING_IN_BANK`

Остальные 7 документов должны сойтись (`MATCHED`).

## Запуск

```bash
python scripts/reconcile_demo.py
```

Скрипт stdlib-only (csv, datetime): матчинг по номеру документа, допуск по сумме 0.01,
даты принимаются в форматах DD.MM.YYYY / YYYY-MM-DD / DD/MM/YYYY.
